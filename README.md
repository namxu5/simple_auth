Dự án simple_auth là bài thực hành thuộc LAB-5 môn Lập Trình Web với Node.js.  
Mục tiêu của dự án là giúp sinh viên hiểu cách cài đặt cơ chế xác thực trong ứng dụng web Node.js, bao gồm:

- Basic Authentication: Kiểm tra thông tin đăng nhập thông qua HTTP Header.
- Cookie Authentication: Lưu thông tin người dùng trên trình duyệt bằng cookie, cho phép duy trì phiên đăng nhập.

Dự án được xây dựng bằng Node.js + Express, có thể chạy và kiểm thử trực tiếp bằng Postman.
